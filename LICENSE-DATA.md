# Bundled data licences

| Data | Source | Licence |
|---|---|---|
| State / UT boundaries (`data/geo/states.geojson`, `india_outline.geojson`) | DataMeet India community, `datameet/maps` States/Admin2 | CC BY 4.0 — "India boundaries by DataMeet India community" |
| District boundaries (`data/geo/districts.geojson`) | DataMeet India community, `datameet/maps` Districts/Census_2011 | CC BY 2.5 India |
| District census attributes (embedded in districts.geojson) | Census of India 2011 Primary Census Abstract (district compilation) | Government of India open data |
| Rivers, lakes, coastline, physical regions, neighbouring countries | Natural Earth 10m/50m | Public domain |
| Country indicators (`data/reference/worldbank_reference.json`) | World Bank, World Development Indicators | CC BY 4.0 |
| AQI breakpoints (`data/aqi/cpcb_breakpoints.json`) | Central Pollution Control Board, National AQI (2014) | Public document |

Boundaries are simplified for display. Depictions of international boundaries follow the
DataMeet India dataset. llama.cpp binaries bundled in Windows packages are MIT-licensed
(https://github.com/ggml-org/llama.cpp). No language model is bundled.
